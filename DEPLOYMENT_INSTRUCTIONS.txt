🔧 POST-DEPLOYMENT CONFIGURATION (Required)

Before going to production:

1. Change Database Password
   ├─ Edit: /opt/hr-autonomous/.env
   ├─ Find: DATABASE_URL=postgresql://hr_app:hr_secure_password_change_me@...
   ├─ Change: Use secure generated password
   └─ Restart: sudo systemctl restart srp-autonomous-hr

2. Generate Secret Key
   ├─ Generate: python3 -c "import secrets; print(secrets.token_urlsafe(32))"
   ├─ Edit: .env file
   ├─ Set: SECRET_KEY=<generated-value>
   └─ Restart: sudo systemctl restart srp-autonomous-hr

3. Enable Backups
   ├─ Create: daily backup script
   ├─ Command: docker exec hr-postgres pg_dump -U hr_app hr_multitenant
   ├─ Schedule: Add to crontab for 3 AM daily
   └─ Retention: Keep last 7 days

4. Configure Email (Optional)
   ├─ Set: EMAIL_PROVIDER=smtp
   ├─ Set: SMTP_HOST, SMTP_PORT, SMTP_USERNAME, SMTP_PASSWORD
   └─ Restart: sudo systemctl restart srp-autonomous-hr
